# MedEasy frontend

React + TypeScript + Vite + Tailwind. Talks to the FastAPI catalogue at `VITE_API_BASE_URL` (default `http://127.0.0.1:8000`).

```bash
npm install
npm run dev
```

Start the backend on port 8000 first. Homepage CTAs go to `/scan` and `/medicines`. Catalogue counts and prices are loaded from the API.
